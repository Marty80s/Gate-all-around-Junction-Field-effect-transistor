# Project version history

## Earlier report

[Final_report_TCAD.pdf](Final_report_TCAD.pdf) is an unchanged copy of the supplied `Final_report_TCAD (3).pdf`.

The project owner clarified that this report was completed **before the FET was refined**. It covers the earlier planar/GAA comparison and records the team's contributions. It is historical documentation, not the specification or validation report for the later refined device.

## Later refined project

The subsequently supplied GAA project archives contain the later refined work. The main packaged prototype comes from `Molybdenum/Prototype_1`, alongside earlier experimental variants from the other archives.

The source decks and numerical data describe their own configurations:
- Archived output sweep: gate held at 0 V, drain swept to 10 V.
- Archived transfer sweep: drain held at 10 V, gate swept to −2 V.

Differences between these files and the earlier report should be understood in that version context. In particular, the earlier report's statement that GAA transfer characteristics were not extracted does not mean the later project lacks a transfer sweep.

Report figures and Table I metrics have not been substituted for values extracted from the later archived data. The repository does not claim that the current decks reproduce the earlier report.

## Preservation and verification

The report PDF is preserved unchanged. The source code and archived curves were not modified when adding it. No Sentaurus rerun or independent device calibration was performed. The report's IEEE-style formatting is not treated as evidence of journal publication.
